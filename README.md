# Aryan Singh — Developer Portfolio

A responsive, dark-first React portfolio built with Vite, Tailwind CSS, Framer Motion, and Lucide React.

## 1. Open in VS Code

1. Download and extract `aryan-singh-portfolio.zip`.
2. Open VS Code.
3. Select **File → Open Folder…** and choose the extracted `aryan-singh-portfolio` folder.
4. Open **Terminal → New Terminal**.

## 2. Install prerequisites

Install Node.js (LTS) from https://nodejs.org/ if it is not already installed.

Check your versions:

```bash
node -v
npm -v
```

## 3. Install dependencies

In the VS Code terminal, run:

```bash
npm install
```

## 4. Start the development server

```bash
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## 5. Build for production

```bash
npm run build
npm run preview
```

The optimized static site is generated in `dist/`.

## 6. Add your resume

Your uploaded resume PDF is already included in `public/Aryan-Singh-Resume.pdf`. The Resume buttons download this actual PDF.

## 7. Contact form behavior

The form validates required fields and email format, then opens the visitor's configured email application using a pre-filled `mailto:` message. It does **not** send messages to a server. For production form delivery, connect a backend endpoint or an email service (for example, Formspree, EmailJS, or your own API) and replace the `submit` handler in `src/App.jsx`.

## 8. Customize content

- Main portfolio content and sections: `src/App.jsx`
- Colors, layout, responsiveness, animations: `src/index.css`
- SEO title and metadata: `index.html`

## Included

- Sticky responsive navigation with mobile menu
- Dark/light theme toggle
- Hero section and animated developer illustration (CSS-built; no stock photo)
- About, education, categorized skills, experience, projects, achievements, coding profiles
- Custom CSS project preview mockups
- Contact form validation and mailto handoff
- Responsive layouts and reduced-motion support
- SEO metadata and production build setup

## Before publishing

Please verify every factual detail, especially the internship dates and certification details, and add the actual resume PDF. The experience and achievements are presented exactly as supplied in the project brief. Consider adding a favicon, a custom domain, and a real contact endpoint before launch.
